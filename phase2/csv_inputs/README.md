# Phase 2 CSV Inputs

Drop refreshed autogenerated CSV files here for each new phase-two run.

If the upstream delivery arrives first as spreadsheets, place those raw files in `phase2/source_exports/` and convert them before updating this folder.

## Expected Inputs

- `agent_inventory.csv`
  - Current Wazuh agent list or host inventory snapshot.
- `deployed_rules.csv`
  - Current deployed rule inventory from the target Wazuh environment.
- `candidate_rules.csv`
  - New or updated rules proposed for the next implementation cycle.
- `rule_test_results.csv`
  - Validation or logtest results exported by external scripts.
- `deployment_status.csv`
  - Deployment outcome or rollout tracking exported by external scripts.

## Workflow

1. Replace the files in this folder with the newest CSV exports for the current run.
2. Treat these files as ephemeral run inputs, not as hand-edited source-of-truth documents.
3. Use the latest CSV set to update the phase-two master workflow document in `docs/PHASE_TWO_MASTER.md`.
4. Keep the latest source spreadsheets in `phase2/source_exports/` only as intake artifacts when needed.

## Notes

- The CSVs are generated elsewhere and are expected to change every run.
- Keep filenames stable where possible so the review and rollout workflow stays consistent.
- If upstream exports are delivered as `.xlsx` first, convert them to CSV before using this folder.
